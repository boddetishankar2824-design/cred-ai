# CRED AI Financial Assistant

An intelligent financial assistant web application with FastAPI backend and responsive HTML/CSS frontend.

## Git Repository
- Remote URL: `https://github.com/boddetishankar2824-design/cred-ai.git`

## Setup & Running Instructions

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the Application
```bash
uvicorn app.main:app --reload --port 8000
```
Open your browser at `http://localhost:8000` to view the application dashboard.

### 3. Connect to Git Repository
In your VS Code terminal, run:
```bash
git init
git remote add origin https://github.com/boddetishankar2824-design/cred-ai.git
git add .
git commit -m "Initial commit of CRED AI application"
git branch -M main
git push -u origin main
```
